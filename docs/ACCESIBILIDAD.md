# Accesibilidad e inclusión

El sistema cumple el nivel AA de WCAG 2.1 sin activar ningún ajuste y ofrece un Centro de accesibilidad con 23 opciones guardadas por usuario en la base de datos.

- **Visual:** tamaño de texto de 100 a 200 %, tipografía de alta legibilidad, espaciado, tema claro, oscuro o automático, tres niveles de contraste y reducción de movimiento.
- **Auditivo:** lectura por voz, subtítulos y transcripción, intérprete de Lengua de Señas Peruana.
- **Navegación y teclado:** atajos con Alt, foco visible, enlace para saltar al contenido y tiempo de sesión ampliable.
- **Idioma:** español, inglés, quechua (Runasimi) y aymara.
- **Contraste verificado:** texto de acento de 3,25:1 a 4,86:1 (#0093B0 a #00748C); estados de 5,19:1, 5,36:1 y 4,97:1.
