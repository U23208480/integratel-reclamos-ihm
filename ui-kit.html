Integratel UI Kit

Mini Design System del Sistema de Gestión de Reclamos y la web institucional. Componentes agrupados en Botones, Formularios, Navegación, Tarjetas y Alertas, cada uno con sus estados: normal, hover, activo, foco y deshabilitado. Usa las mismas clases del sistema real (assets/css/style.css).
